This section has two types of pages:

* **Example sites** are complete, copy-paste-ready site configurations. Use them as a starting point for a new site. Each example uses the current `github.com/gohugo-ananke/ananke/v2` module path and the `[ananke]` parameter namespace.
* **Recipes** are short solutions for one task, for example adding a missing social icon.

The example sites come first in the list below, then the recipes. Do you have a recipe that other people can use? Read [Contributing to the documentation](/help/contributing/).
