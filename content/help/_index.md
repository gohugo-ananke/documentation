Use the pages in this section when something does not work as you expect, or when you want to help improve Ananke and its documentation.

If you think that you found a bug in the theme, read [Troubleshooting](/help/troubleshooting/) first. It explains which information to include. Then open an issue in the [Ananke theme repository](https://github.com/gohugo-ananke/ananke/issues).
